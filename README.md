## Установка / еще ниже есть подробный гайд

1. Установите Tampermonkey: [Chrome / Edge / Brave](https://www.tampermonkey.net/?browser=chrome) или [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/).
2. УСтановить сам скрипт [![Установить в Tampermonkey](https://img.shields.io/badge/Tampermonkey-Установить-00485B?logo=tampermonkey)](https://raw.githubusercontent.com/App1epli/FSP/main/FSP.user.js)
3. Подтвердите установку в открывшемся окне Tampermonkey.
4. Разрешите пользовательские скрипты в настройках расширения
5. Откройте или обновите [WSP KBTU](https://wsp.kbtu.kz/).
